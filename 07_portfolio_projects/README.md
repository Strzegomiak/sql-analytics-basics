# Portfolio Projects

This folder contains business-oriented data analytics portfolio projects focused on real analytical workflows and decision-making processes.

The projects combine:

- SQL
- PostgreSQL
- Excel
- Power BI
- business KPI analysis

The project analyzes:

- revenue trends
- customer behaviour
- product performance
- return patterns
- customer segmentation
- business KPIs

Key analytical areas:

- revenue analysis
- customer concentration analysis
- Pareto distribution
- return rate analysis
- seasonal trends
- customer activity analysis

Main focus:
identifying business insights and performance drivers within retail/e-commerce data.

## 2️⃣ Checkout A/B Test Analysis

End-to-end Product Analytics / Data Analytics case study focused on evaluating a checkout redesign experiment.

The project analyzes:

- conversion uplift
- revenue impact
- experiment validation
- segment performance
- guardrail metrics
- business impact estimation

Key analytical areas:

- A/B testing analysis
- conversion analysis
- KPI interpretation
- guardrail metrics
- business recommendations
- product analytics workflow

Main focus:
evaluating whether the new checkout experience should be rolled out to all users based on analytical evidence and business impact.
